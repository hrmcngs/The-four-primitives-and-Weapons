# Gate の基準: gate1-16

参照元: `/Users/hiromichi/Downloads/gate1-16/`。画像より、このパックの命令を仕様の根拠にする。
`pack.mcmeta` の `pack_format` は4。フォルダ名だけで対応バージョンや動画との完全一致は断定しない。

## 読み取れる処理

- `data/minecraft/tags/functions/load.json` → `superdog:good`。
- `data/minecraft/tags/functions/tick.json` → 毎tick `superdog:poof`。
- `good.mcfunction` はスコアボードを登録。`use` の統計は **carrot_on_a_stick** の使用回数。
- `crafting/recipes/crafting_recipe.json` はエンダーアイ・ウィザースケルトンの頭・ダイヤ剣から知恵の本を作るレシピ。このパック内に、その知恵の本をGateへ変換する関数はない。

## 今回のMODへの反映と相違

- 画像から追加した18本・3段・時間差連射と拡大/常時最大照度を取り消した。
- 3本の横・高さ・前後差、照準50ブロック、通常15tickの待機、毎tick4ブロック、召喚から50tickで爆発せず消滅、照準5ブロック以内で消滅を反映。
- 待機中も金色粒子を出し、使用者がGateを持つ間は照準方向を更新。発射後の方向は固定する。
- ドロップキーで召喚し、Gateは手元に戻る。元の「捨ててから再支給」に相当する。Shift+ドロップで通常どおり手放せる。UUIDと発生経路の区別は [drop-provenance.md](drop-provenance.md) を参照。
- MOD既存の右クリック召喚も残す。これは元パックのcarrot_on_a_stick/fl系とは異なる操作上の拡張。
- 生成位置は使用者の位置・水平向きを基準とし、防具立ての手元相当の高さとして1ブロックを加える。元は落ちたアイテムの位置・回転基準なので完全な座標一致ではない。
- `limit=1` の世界全体での任意選択と二重移動は再現せず、各使用者の3本は通常の15tick待機に統一。常時追尾する例外の1本も追加しない。
- TNT召喚、地形破壊、特殊な近接起爆、周囲の無関係なドロップ削除は今回の射出処理へ追加していない。既存MODの直撃ダメージと地形を壊さない命中爆発を維持。既存の儀式用GateEventHandlerは今回の修正対象外。
- 収束型の射出数・照準距離・寿命は通常Gateとは別の既存設定を維持。

コンパイルとリソース生成で検証する。ゲーム内での実操作、描画、マルチプレイの確認は別途必要。
