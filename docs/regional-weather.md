# バイオーム別の天気

オーバーワールドに、WMOの現在天気コード（表4677）を参考にした11種類の天候と晴れを追加しています。コードは分類の参考であり、観測履歴まで含むWMO通報の完全な再現ではありません。バイオームの制限はこのMODのゲームルールです。

出典: [WMO Code 4677（NOAA公開資料）](https://www.nodc.noaa.gov/archive/arc0021/0002199/1.1/data/0-data/HTML/WMO-CODE/WMO4677.HTM)

## コマンド

管理者権限（レベル2）が必要です。

| コマンド | 天候 | WMO参考コード |
| --- | --- | --- |
| `/weather clear` | 晴れ | — |
| `/weather fog` | 霧 | 45 |
| `/weather drizzle` | 霧雨 | 51 |
| `/weather rain` | 雨 | 63 |
| `/weather heavy_rain` | 強い雨 | 65 |
| `/weather snow` | 雪 | 73 |
| `/weather heavy_snow` | 強い雪 | 75 |
| `/weather showers` | にわか雨 | 80 |
| `/weather thunderstorm` | 雷雨 | 95 |
| `/weather hail` | 雷を伴うひょう | 96 |
| `/weather sandstorm` | 砂嵐 | 31 |
| `/weather blowing_snow` | 地吹雪 | 38 |
| `/weather auto` | 種類の固定を解除 | — |
| `/weather status` | 現在地の天候を表示 | — |

指定した種類はワールドに保存され、参加・リスポーン・ディメンション移動時にも同期されます。種類の指定はオーバーワールド全体で共有し、実際に発生するかは各地点のバイオームと時刻で判定します。禁止された場所では晴れになります。

`/weather <種類> [期間]`で指定できます。期間は`600`（tick）、`30s`（秒）、`1d`（ゲーム内の1日）のように書き、省略すると12000 tick（通常速度で約10分）です。例えば`/weather heavy_rain 60s`。`/weather thunder`は`thunderstorm`と同じです。

期間はバニラの晴天・降水タイマーに適用します。種類の固定自体には有効期限がなく、降水時間が終わると雨・雪・ひょうは止まりますが、霧・砂嵐・地吹雪は`/weather clear`または`/weather auto`まで固定されます。自動に戻す操作だけでは雨は開始しません。`/weather rain`は雨の種類を固定します。自動分類で降水を開始する場合は`/weather rain`の後に`/weather auto`を実行してください。

以前の`/climate set <種類>`、`/climate auto`、`/climate status`も互換用に使えます。

## 発生条件

| 場所 | 発生する天候・制限 |
| --- | --- |
| 通常の温暖な降水バイオーム | 雨系・雷雨・ひょう。雪・砂嵐は発生しない |
| 湿潤バイオーム（downfallが0.7以上） | 条件を満たす雨系に加えて霧 |
| その地点でバニラが雪と判定する寒冷地 | 雪・強い雪・地吹雪。液体の雨は発生しない |
| 砂漠 | 昼は雨なし。夜（13000以上23000未満）は雨・霧雨・強い雨・にわか雨を許可。砂嵐あり。雷雨・ひょう・霧・雪なし |
| 荒野・侵食された荒野・森のある荒野 | 砂嵐あり。雨・雪・雷・霧なし |
| サバンナ・サバンナの高原・吹きさらしのサバンナ | 雨・雪・雷・霧・砂嵐なし |
| ネザー・エンド・その他のディメンション | この追加天候の対象外 |

砂漠は毎晩必ず雨になるわけではありません。ワールドが降水中で、夜の条件も満たすと雨が降ります。自動モードでは、昼の砂漠の降水期間は砂嵐になります。

砂漠の夜の雨を確認するには、砂漠に移動して次を実行します。

```mcfunction
/time set 18000
/weather rain
/weather status
```

自動天候の雨を確認する場合は次の順番です。

```mcfunction
/weather rain
/weather auto
```

自動モードはバニラの雨・雷の周期を使い、6000 tickごとのパターンとバイオーム条件から種類を選びます。晴天時の湿潤地では一部の明け方に霧が出ます。にわか雨は600 tick周期で360 tickの降水と240 tickの休止を繰り返します。

## 見た目とゲーム内判定

雨・雪の描画、雨に濡れる判定、降水を受けるブロック、積雪、落雷を地域の天候に合わせます。霧・砂嵐・地吹雪は視界や粒子で表現し、ひょうには粒子を追加しています。ひょう・砂嵐による専用ダメージはありません。

バニラの空の暗さや雲、シェーダーの濡れ表現の一部はワールド共通の雨状態を参照します。すべての空の表現がバイオーム境界で切り替わるわけではありません。VanillaLite 2.0.8-testでは、薄い霧雨の透過、地域の霧・砂嵐・地吹雪の視界、MODが描く天候別の空に対応しています。

天文現象の設定とは独立しているため、月の色・サイズ・月相・流星・日食・月食と併用できます。

## 天候による空の変化

シェーダーの有無にかかわらず、MODが現在地の天候に合わせた雲と空の霞を描画します。

| 天候 | 空の表示 |
| --- | --- |
| 晴れ | 切れ間の多い、ゆっくり流れる雲 |
| 霧・霧雨 | 薄い雲の層と霞。霧では霞が濃くなる |
| 雨・強い雨 | 灰色の厚い雲。強い雨では覆う範囲と霞が増える |
| にわか雨 | 切れ間を残して速く流れる雨雲 |
| 雷雨・ひょう | 空を広く覆う暗い雲 |
| 雪・強い雪 | 白灰色の雲。強い雪では空の霞も濃くなる |
| 砂嵐 | 砂色の雲状の砂塵と、地平線付近の濃い霞 |
| 地吹雪 | 速く流れる白灰色の雲と霞 |

雲の明るさは昼夜でも変化します。雲や霞は太陽・月・星の前に重なり、天文現象と併用できます。ネザー・エンドの空は対象外です。

ゲームの「雲」をOFFにすると追加した雲も非表示になりますが、天候の霞は残ります。VanillaLiteでは雲設定の「MODの天候別の空」（`TFPAW_WEATHER_SKY`）をONにすると、シェーダー側の雲を停止して二重表示を防ぎます。2.0.8-testでは既定でONです。MODを入れずにパックだけを使う場合はOFFにしてください。他のシェーダーパックで同じ表示になることは保証していません。

## 天候の音とパーティクル

追加音は「サウンド設定 → 天候」の音量に従います。既存の雨音・落雷音はそのまま使い、追加する環境音だけを短くフェードさせます。

| 天候 | 音 | 追加パーティクル |
| --- | --- | --- |
| 晴れ | 追加なし | なし |
| 霧 | 追加なし | 薄い霧の粒子 |
| 霧雨 | 小さめの既存雨音 | 少量の雨粒・水しぶき |
| 雨・にわか雨 | 既存雨音 | 雨粒・水しぶき |
| 大雨 | 雨音＋弱い風音 | 多めの雨粒・水しぶき |
| 雷雨 | 雨音＋風音。落雷時は既存の雷鳴 | 強い雨粒・水しぶき |
| 雪 | 追加なし | ゆっくり降る雪片 |
| 大雪 | 風音 | 多めの雪片 |
| ひょう | 雨音＋粒が打ちつける音。落雷時は雷鳴 | 白い氷粒 |
| 砂嵐 | 砂が吹きつける音 | 横へ流れる砂塵 |
| 地吹雪 | 強い風音 | 横へ流れる雪片 |

にわか雨の休止中は追加の雨粒も止まります。追加粒子は屋外の空いている地点に発生し、ゲームのパーティクル設定「少なめ」「最小」に従って減ります。追加環境音は屋内で小さくなり、水中や地表から12ブロックより深い場所では消えます。天候変更・ディメンション移動・退出でも停止します。バニラの雨音については既存の処理が引き続き適用されます。

シェーダーなしでも音と粒子は動作します。風・砂・ひょうの音源はこのMOD用に合成したもので、`scripts/audio/generate_weather_sounds.py`（Python 3とffmpeg）から再生成できます。日本語・英語の字幕にも対応しています。

## メニューとデータパック

`sh/menu.sh`のtimeコマンド生成から天候も選択できます。直接起動する場合は`bash sh/generate/generate-time-commands.sh`です。

バイオーム制限は以下のタグで拡張できます。

```text
data/the_four_primitives_and_weapons/tags/worldgen/biome/weather/no_rain.json
data/the_four_primitives_and_weapons/tags/worldgen/biome/weather/no_snow.json
data/the_four_primitives_and_weapons/tags/worldgen/biome/weather/no_thunder.json
data/the_four_primitives_and_weapons/tags/worldgen/biome/weather/no_fog.json
data/the_four_primitives_and_weapons/tags/worldgen/biome/weather/sandstorms.json
```

例えば`no_rain.json`に`{"replace":false,"values":["minecraft:desert"]}`を追加すると、砂漠の夜間の例外より禁止タグが優先され、砂漠でも雨が降らなくなります。`sandstorms`は乾燥バイオームに対して有効です。タグから禁止を外しても、寒冷地・乾燥地などの基本条件は残ります。

検証: `bash sh/test/test-regional-weather.sh`
