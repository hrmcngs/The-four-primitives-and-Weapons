# 「約束の果てに」とring

ストーリーモードへ接続するための武器呼び出し機能。現段階では物語の進行条件や固有能力は未実装。

## 使い方

1. クリエイティブの武器タブ、または `/give @s the_four_primitives_and_weapons:ring` で指輪を入手する。
2. Curiosの `ring` スロットへ装備する。
3. 既存のRキーを長押しし、抜刀ホイールで刀・剣・直刀を選んで離す。
4. 「約束の果てに」をメインハンドへ抜刀する。インベントリに同じ形がある場合はその実物を移動する。
5. R短押しは既存の鞘を優先し、鞘がなければringの前回の形（初回は刀）を抜刀する。
6. 武器を持ってR長押しし、納刀先にringを選ぶと戻せる。通常の対応する鞘にも納刀できる。

手持ちや通常のインベントリに指輪を置くだけでは呼び出せない。ringからの抜刀にはメインハンドの空きが必要。ringへ戻した武器は耐久値・エンチャント・保存情報を維持する。新規呼び出しの間隔は1秒。

## 現在の仮仕様

- 名前は3つの形すべて「約束の果てに」。ツールチップで形を表示。
- 刀・直刀は既存のダイヤ系モデル、剣はバニラのダイヤ剣モデルを使用。
- ダイヤ素材、攻撃力7、攻撃速度1.6、レアリティEPIC。
- それぞれ既存の刀・剣・直刀の武器タイプに登録し、通常のスキル設定を利用する。
- ringを外しても呼び出し済みの武器は残る。

## ストーリー連携用の識別情報

| 用途 | 値 |
|---|---|
| 指輪のアイテムID | `the_four_primitives_and_weapons:ring` |
| 刀 | `the_four_primitives_and_weapons:promise_katana` |
| 剣 | `the_four_primitives_and_weapons:promise_sword` |
| 直刀 | `the_four_primitives_and_weapons:promise_straight_sword` |
| 呼び出した武器の `StoryWeaponId` | `promise_end` |
| 指輪と武器の `PromiseRingId` | 呼び出し元の指輪を識別するUUID |
| 呼び出した武器の `PromiseOwner` | 呼び出したプレイヤーのUUID |

抜刀・納刀は既存のホイールと通信パケットを使用する。呼び出し条件は `PromiseRing.draw` に集約している。今後のストーリー解放条件はここへ追加できる。表示名だけで識別せず、アイテムIDと保存情報を使用する。
