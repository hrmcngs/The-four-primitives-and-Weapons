# 月の大きさの周期

オーバーワールドの月は、32ゲーム日で通常の0.8〜1.2倍の大きさを滑らかに往復します。
満ち欠けは従来の8日周期のままです。満月と月の接近が重なる夜は「スーパームーン」、
満月と月の遠ざかりが重なる夜は「マイクロムーン」として、既存の夜入り通知に表示します。
大きさによる追加の難易度補正はありません。

ワールドの日時を使うため、マルチプレイでも同じ日時には同じ大きさになります。
睡眠や `/time` によって日時が進むと、その日時の大きさに変わります。
`doDaylightCycle` が false の間は大きさも止まります。

動作確認（チート権限が必要）:

- `/time set 18000`: 最初の満月の深夜。最大の1.2倍。
- `/time set 210000`: 8日後の満月の深夜。通常の1.0倍。
- `/time set 402000`: 16日後の満月の深夜。最小の0.8倍。
- `/time set 786000`: 32日後の満月の深夜。再び最大の1.2倍。

通知を確認するには、いったん `/time set 12000` で昼に戻して1秒以上待ち、
`/time set 13000`（スーパー）または `/time set 397000`（マイクロ）で夜入りさせます。
雨天や新月では従来どおり月が見えにくくなります。独自に空を描画するシェーダーやMODは
バニラの月描画を使わないため、この大きさ変更が反映されない場合があります。

## ブルームーン・ブラッドムーン・流星

以下はゲーム独自の天文イベントです。すべてオーバーワールドで発生し、
ワールドの日時に同期します。特殊な夜の名前は既存の夜入り通知に表示されます。

| 現象 | 周期（ワールド初日を0日とする） | 演出 |
| --- | --- | --- |
| ブルームーン | 8日目から32日ごとの満月 | 月が青くなる |
| ブラッドムーン | 24日目から64日ごとの満月 | 月が赤くなる |
| 流星 | 毎晩、約16秒ごと | 約1.2秒で光の尾を引いて消える |
| 流星群 | 7日目から16日ごと | 流星が約2秒ごとに現れる |

月のサイズ周期・満ち欠け・既存の難易度補正は維持されます。
特殊な月による敵の強化や流星の落下ダメージはありません。
流星は夜間（13000〜23000 tick）に頭上の空に描画され、雨や雷雨では薄くなります。
天井や地形に遮られ、水中など通常の空が描画されない場所では表示されません。
時刻を停止すると流星の動きも止まります。空を置き換えるシェーダーやMODでは、
月の色・流星が反映されない場合があります。

確認用コマンド（晴天のオーバーワールドで空を見上げる）:

- `/time set 210000`: ブルームーン。
- `/time set 594000`: ブラッドムーン。
- `/time set 186000`: 流星群。数秒待つと繰り返し流れる。

通知を確認する場合は、先に昼に戻して1秒以上待ってから上記の時刻へ進めてください。

## VanillaLite

VanillaLite-v2.0.3-test.zip は月のサイズ・色と流星の描画に対応しています。
`run/shaderpacks/` に配置済みです。ゲーム内のシェーダー選択画面でこの版を選び、
シェーダーを有効にして適用してください。月の描画方式1/2/3に対応しています。
シェーダー生成の月はVanillaLite側でも同じ周期を計算し、流星は本体の描画を通します。
対応コードは `/Users/hiromichi/Documents/github/mods/VanillaLite/` にあります。
静的チェック・ZIP整合性は確認済みですが、GPU上のコンパイル・見た目は未確認です。


## 日食と月食

ゲーム独自の64日周期です。初日を0日として、12日目（新月）の4000〜8000 tickは日食、
48日目（満月）の16000〜20000 tickは月食です。日時を停止すれば進行も止まります。
日食では影が太陽を横切り、月食では月が徐々に暗い赤銅色になってから戻ります。
日食は開始時、月食は既存の夜入り通知で知らせます。ブラッドムーンは別の夜に発生します。
世界の照明・敵の難易度には追加補正を入れません。

- `/time set 292000`: 日食開始。約3分20秒で終わる。
- `/time set 294000`: 日食最大。
- `/time set 1168000`: 月食開始。約3分20秒で終わる。
- `/time set 1170000`: 月食最大。

晴天のオーバーワールドで確認してください。VanillaLite-v2.0.3-testを開発環境の
`run/config/oculus.properties` で選択し、`enableShaders=true` を設定済みです。
既にゲームが起動中の場合は再起動が必要です。
