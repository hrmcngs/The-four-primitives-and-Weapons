# 月の大きさの周期

オーバーワールドの月は、32ゲーム日で通常の0.8〜1.2倍の大きさを滑らかに往復します。
満ち欠けは従来の8日周期のままです。満月と月の接近が重なる夜は「スーパームーン」、
満月と月の遠ざかりが重なる夜は「マイクロムーン」として、既存の夜入り通知に表示します。
大きさによる追加の難易度補正はありません。

ワールドの日時を使うため、マルチプレイでも同じ日時には同じ大きさになります。
睡眠や `/time` によって日時が進むと、その日時の大きさに変わります。
`doDaylightCycle` が false の間は大きさも止まります。

動作確認（チート権限が必要）。手動指定中は先に `/astronomy reset` で自然周期に戻してください:

- `/time set 18000`: 最初の満月の深夜。最大の1.2倍。
- `/time set 210000`: 8日後の満月の深夜。通常の1.0倍。
- `/time set 402000`: 16日後の満月の深夜。最小の0.8倍。
- `/time set 786000`: 32日後の満月の深夜。再び最大の1.2倍。

通知を確認するには、いったん `/time set 12000` で昼に戻して1秒以上待ち、
`/time set 13000`（スーパー）または `/time set 397000`（マイクロ）で夜入りさせます。
雨天や新月では従来どおり月が見えにくくなります。独自に空を描画するシェーダーやMODは
バニラの月描画を使わないため、この大きさ変更が反映されない場合があります。

## ブルームーン・ブラッドムーン・流星

以下はゲーム独自の天文イベントです。すべてオーバーワールドで発生し、
ワールドの日時に同期します。特殊な夜の名前は既存の夜入り通知に表示されます。

| 現象 | 周期（ワールド初日を0日とする） | 演出 |
| --- | --- | --- |
| ブルームーン | 8日目から32日ごとの満月 | 月が青くなる |
| ブラッドムーン | 24日目から64日ごとの満月 | 月が赤くなる |
| 流星 | 毎晩、約16秒ごと | 約1.2秒で光の尾を引いて消える |
| 流星群 | 7日目から16日ごと | 3つの軌道で、それぞれ約2秒ごとに現れる |

月のサイズ周期・満ち欠け・既存の難易度補正は維持されます。
特殊な月による敵の強化や流星の落下ダメージはありません。
自然発生の流星は夜間（13000〜23000 tick）に低い空から頭上まで全方角に分散して描画され、雨や雷雨では薄くなります。
天井や地形に遮られ、水中など通常の空が描画されない場所では表示されません。
時刻を停止すると流星の動きも止まります。空を置き換えるシェーダーやMODでは、
月の色・流星が反映されない場合があります。

確認用コマンド（晴天のオーバーワールドで空を見上げる）:

- `/time set 210000`: ブルームーン。
- `/time set 594000`: ブラッドムーン。
- `/time set 186000`: 流星群。数秒待つと繰り返し流れる。

通知を確認する場合は、先に昼に戻して1秒以上待ってから上記の時刻へ進めてください。

## 日食と月食

ゲーム独自の64日周期です。初日を0日として、12日目（新月）の4000〜8000 tickは日食、
48日目（満月）の16000〜20000 tickは月食です。日時を停止すれば進行も止まります。
日食では影が太陽を横切り、月食では月が徐々に暗い赤銅色になってから戻ります。
日食は開始時、月食は既存の夜入り通知で知らせます。ブラッドムーンは別の夜に発生します。
世界の照明・敵の難易度には追加補正を入れません。

- `/time set 292000`: 日食開始。約3分20秒で終わる。
- `/time set 294000`: 日食最大。
- `/time set 1168000`: 月食開始。約3分20秒で終わる。
- `/time set 1170000`: 月食最大。

晴天のオーバーワールドで確認してください。VanillaLite-v2.0.6-testを開発環境の
`run/config/oculus.properties` で選択し、`enableShaders=true` を設定済みです。
既にゲームが起動中の場合は再起動が必要です。

すべて満月の夜に発生し、夜入り通知にも名前が表示されます。初日を0日として数えます。

| 月 | 色 | 自然発生 | 確認コマンド |
| --- | --- | --- | --- |
| ゴールドムーン | 金色 | 16日目から64日ごと | `/time set 402000` |
| ジェイドムーン | 翡翠色 | 32日目から64日ごと | `/time set 786000` |
| バイオレットムーン | 紫 | 56日目から128日ごと | `/time set 1362000` |
| ローズムーン | ピンク | 120日目から128日ごと | `/time set 2898000` |

ゴールドムーンはマイクロムーン、ジェイドムーンはスーパームーンと重なります。
通常の白い満月、ブルームーン・ブラッドムーン、月食は引き続き発生します。

## 流星群と月を個別に指定する

`/astronomy` は管理者権限（レベル2）が必要です。設定はオーバーワールドに適用し、
ワールドへ保存して参加者に同期します。退出・再参加やサーバー再起動後も保持します。

流星群の日に、2倍の翡翠色の三日月を表示する例:

```mcfunction
/weather clear
/time set 186000
/astronomy moon size 2
/astronomy moon phase 5
/astronomy moon color jade
/astronomy meteors on
/gamerule doDaylightCycle true
```

| コマンド | 指定値 |
| --- | --- |
| `/astronomy moon size <倍率>` | 0.25〜4.0。または `auto` で自然周期 |
| `/astronomy moon phase <月相>` | 0:満月、1:居待月、2:下弦、3:二十三夜、4:新月、5:三日月、6:上弦、7:十三夜。または `auto` |
| `/astronomy moon color <色>` | `auto`, `normal`（白）, `blue`, `blood`, `gold`, `jade`, `violet`, `rose` |
| `/astronomy meteors <設定>` | `on`:昼も表示する流星群、`off`:流星を非表示、`auto`:自然周期 |
| `/astronomy effects <設定>` | `on` / `off`:月の色によるプレイヤー効果 |
| `/astronomy status` | 現在の設定を表示 |
| `/astronomy reset` | 全指定を解除し、自然周期・色効果有効へ戻す |

`reset` は日時・天候・doDaylightCycleを変更しません。手動の色は満月以外にも適用できます。
新月は見えません。手動月相は本MODの既存の月相難易度補正にも使われます。
バニラのスライム湧きなど、他の月相依存処理の暦は変更しません。

## 月の色の効果

夜間のオーバーワールドにいる生存プレイヤーにレベルIで適用します。新月と観戦者は対象外です。
自然発生・手動指定のどちらの月にも適用されます。白い月に追加効果はありません。

| 月の色 | 効果 |
| --- | --- |
| 青 | 暗視 |
| 赤 | 攻撃力上昇 |
| 金 | 幸運（対応する戦利品テーブルに作用） |
| 翡翠 | 再生能力 |
| 紫 | 耐性 |
| ピンク | 低速落下 |

夜明け・色の変更・ディメンション移動・効果無効化の後は、暗視は最大12秒、ほかは最大3秒で切れます。
同じ種類の既存の長い効果・強い効果は消しません。撮影だけなら `/astronomy effects off` を使えます。

## shメニューでコマンド生成

```sh
bash sh/menu.sh
# 「生成」→「天文現象・timeコマンドを生成」
```

直接起動する場合:

```sh
bash sh/generate/generate-time-commands.sh
```

SBCLが必要です。日時・大きさ・形・色・流星・日食・月食・効果・時間進行・天候を順に選びます。
結果は `run/generated_commands/astronomy-<日時>/commands.txt` と `generated.mcfunction` に保存します。
ゲームへ自動送信せず、表示されたコマンドを上から順に実行します。
検証は `bash sh/test/test-astronomy.sh` で実行できます。


## バニラの三日月・半月

白色・通常サイズのバニラ月を一度に設定できます。流星群の設定や日時は維持します。

```mcfunction
/astronomy moon vanilla crescent
```

| 月の形 | 指定名 | 月相番号 |
| --- | --- | --- |
| 満月 | `full` | 0 |
| 居待月 | `waning_gibbous` | 1 |
| 下弦（半月） | `last_quarter` | 2 |
| 欠けていく三日月 | `waning_crescent` | 3 |
| 新月（見えない） | `new` | 4 |
| 三日月 | `crescent` | 5 |
| 上弦（半月） | `first_quarter` | 6 |
| 十三夜 | `waxing_gibbous` | 7 |

例: `/astronomy moon vanilla 5` も三日月になります。夜でなければ `/time set night` を実行してください。
shの天文コマンド生成でも、時刻選択の次に「月のプリセット」からバニラの8相を選べます。
白・通常サイズ・選択した月相が初期値になり、その後に大きさや色を変更することもできます。
VanillaLite 2.0.6-testに対応しています。自然周期へ戻す場合は `/astronomy reset` を実行します。


## 天文現象を同時に有効にする

月の大きさ・形・色、流星群、日食、月食は個別に設定でき、後のコマンドで他の指定は消えません。
同じ月の色や大きさはそれぞれ1つですが、「大きい青い満月＋流星群＋月食」などを組み合わせられます。

```mcfunction
/weather clear
/time set 18000
/astronomy moon size 1.2
/astronomy moon phase 0
/astronomy moon color blue
/astronomy meteors on
/astronomy eclipse lunar on
```

この状態から日食も有効にできます。太陽が見える時刻へ移動しても、月・流星・月食の設定は保持されます。

```mcfunction
/astronomy eclipse solar on
/time set 6000
```

| コマンド | 動作 |
| --- | --- |
| `/astronomy eclipse solar on` | 日付を問わず、日食の最大状態（進行0.5）を維持 |
| `/astronomy eclipse lunar on` | 日付・満ち欠けを問わず、月食の最大強度（1.0）を維持 |
| `/astronomy eclipse solar 0.3` | 日食の進行を0〜1で指定（0:開始、0.5:最大、1:終了） |
| `/astronomy eclipse lunar 0.5` | 月食の強度を0〜1で指定（0:通常、1:最も暗い） |
| `/astronomy eclipse solar off` | 日食だけを解除 |
| `/astronomy eclipse lunar off` | 月食だけを解除 |
| `/astronomy eclipse solar auto` | 日食だけを自然周期へ戻す |
| `/astronomy eclipse lunar auto` | 月食だけを自然周期へ戻す |
| `/astronomy reset` | すべての指定を解除して自然周期へ戻す |

太陽と月の位置はバニラどおりです。両方の食を有効にしても、太陽が見える時間は日食、
月が見える時間は月食を確認します。新月は見えないため、月食の観察には満月などを指定してください。
手動の流星群（on）は昼も表示し、自然発生（auto）は夜のみです。天候による減光は維持されます。
月食は選択した月の色に重なって暗く赤銅色になるため、色の見え方も変わります。
バニラ月プリセットも日食・月食の指定を保持します。

手動の食は固定した状態を維持し、自然周期の食は時刻に合わせて進行します。
設定は保存・同期され、旧保存データの食の設定はautoとして読み込まれます。
本体とマルチプレイのクライアント・サーバーを同じ対応版に更新してください。
VanillaLiteは2.0.6-testを使用します。shメニューでも日食と月食を別々に指定できます。

## 天気との併用

天文現象と独立して、バイオーム別の天気も指定できます。コマンドと砂漠の夜間降雨の条件は[バイオーム別の天気](regional-weather.md)を参照してください。timeコマンド生成メニューでも天候を選べます。

## 日食のピクセル表示

VanillaLite 2.0.9-testでは、全スタイルでバニラの四角い太陽テクスチャを使用します。日食はピクセル単位で欠ける影として表示し、最大時も明るい外縁を残します。シェーダー使用時の影には空に合わせた暗い色を使います。MOD側も円形マスクを廃止したため、反映にはゲームの再起動が必要です。

2.0.10-testでは日食と天候の雲の識別色の衝突も修正し、旧版MODが送る大きな円形マスクを破棄します。新しい日食には更新したMODとゲーム再起動が必要です。
