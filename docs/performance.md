# 実行時の軽量化

2026-09-20の変更。描画・天候・戦闘・共通遅延処理を対象に、機能や更新周期を削らず重複計算を減らしています。ゲーム内のFPS/MSPTの改善率は未計測です。

| 対象 | 変更 |
| --- | --- |
| 天候の空 | 球面座標の三角関数を初回だけ計算。共有頂点の雲・霞計算を7,680回/フレームから2,016回に削減（約74%減）。描画する頂点数・形・透明度は維持 |
| 天候判定 | 降水の透明度と種類で同じ地点を二重判定していた処理を統合。通常の天候取得でもバイオーム参照の重複を削減 |
| 天候設定 | 変更されない空・音・粒子の設定を共有し、毎回のオブジェクト生成を削減 |
| 遅延スキル | 全待機処理のカウントダウンから優先度キューへ変更。待機中の処理を毎tick走査しない。実行時刻が同じ処理は登録順を維持 |
| 終了処理 | サーバー終了時に待機中のスキルを解放し、別ワールドへの持ち越しを防止 |
| 追尾矢 | 生存・所有者条件を検索時に適用し、最短候補だけ視野角を計算。消滅済みの矢の参照は走査時に除去 |
| グレイズ | 距離比較を二乗値にして平方根を削減 |
| ブラックホール | 同じ速度を20回設定していた重複を1回に削減 |

既存の通信差分同期・tick間引きは維持しています。範囲攻撃の対象順序は副作用に影響するため、一律のソート除去は行っていません。

## 検証

- `bash sh/test/test-performance.sh`: 差分同期、遅延処理の実行時刻・順序、処理中の追加、並行登録、終了時の解放、全天候で空の旧計算結果との一致。
- `bash sh/test/test-regional-weather.sh`: 天候ルール、保存・同期、コマンド登録。
- `./gradlew build --offline`: MODのビルド。

空の計算削減率はCPU側の当該計算回数の比較で、FPSの改善率ではありません。実際の効果はエンティティ数、同時発動スキル数、描画距離、シェーダーなどによって変わります。比較時は同じワールド・位置・設定を使用してください。
