Minecraft Java版MODの「和風ファンタジーのショート羽織＋魔法騎士の鎧一式」をデザインし、ゲームに使えるテクスチャと3Dモデルを作ってください。ショート羽織に加えて、兜・胸当て（肩・腕を含む）・脚甲・ブーツも対象です。

【参考衣装の使い分け・今回の変更点】
羽織の参考は「壱ノ桜・桜花」（初音ミク／Project DIVAの千本桜衣装）です。和装ジャケットの雰囲気を取り入れ、ファンタジー世界で鎧に重ねられる短い羽織にしてください。足首まであるロングマントという以前の方向は取り消します。
参考衣装の確認先：
https://info.miku.sega.jp/3245
https://w.atwiki.jp/projectdiva_ac/pages/1865.html
可能ならユーザーが添付する壱ノ桜・桜花の画像を優先し、参照画像を確認できない場合は確認できたふりをしないでください。
羽織で参考にするのは、短い身頃、和装らしい襟と前合わせ、ゆったりした袖、和風とファンタジーが混ざる雰囲気です。帽子・スカート・髪型など衣装全体を再現する依頼ではありません。
鎧は別途添付する仮面ライダーブレイブ ファンタジーゲーマー レベル50の写真を参考にします。「タドルファンタジー」らしい横に張り出す肩装甲、立体的な胸当て、魔法騎士の威厳を取り入れます。
どちらもそのままの複製にはせず、顔・角・模様・赤青の色配置・変身ベルトなど固有の意匠をトレースしないでください。オリジナルの和風ファンタジー装備として統一してください。

【画風】
最優先は「実際のMinecraftに装備して違和感がないこと」です。
・バニラのプレイヤー体型に合う、角ばった立体モデル。
・マイクラらしい低解像度のドット絵。四角い画素、階段状の輪郭、少ない色数、2〜3段階の明確な陰影。
・羽織は黒〜濃い紫を主体に、襟や袖口に落ち着いた差し色を少量使う。暗色でも形が読める控えめな明暗にする。鎧は黒と鈍い銀を基調に、深い赤紫や青緑を要所に使うなど、参考衣装と区別できる配色にする。
・羽織の質感は少し厚みのある布。鎧の質感は角ばった金属板と控えめな魔力の結晶。布を薄い紙や板、ビニールに見せない。
・ひだの表現はモデル形状とテクスチャを合わせる。平面に細かい縦縞を貼っただけにしない。
・写実的な繊維、光沢、なめらかなグラデーション、ぼかし、アンチエイリアス、ノイズを避ける。
・羽織を大きな翼・剣の紋章や豪華な刺繍で埋めない。和風らしさは襟・袖・短い身頃を中心に表現し、柄を入れるなら低解像度でも読める控えめなものにする。鎧には面の切り替えや控えめな縁取りを使ってよいが、細かい彫金で埋め尽くさない。文字・ロゴは装備全体に付けない。
・解像度の高いイラストを単に縮小してドット絵にするだけではなく、低解像度で読める形を設計する。

【ショート羽織の形】
・腰あたりで終わる短い身頃。体格に合わせ、丈は肩から約10〜12モデル単位を目安にする。膝や足首まで伸ばさない。
・背中だけに短い布を付ける形ではなく、襟・前身頃・後ろ身頃・袖を備えた羽織ものとして設計する。
・前は開けるか軽く合わせ、下の鎧の胸当てや帯が見えるようにする。着物のように胴を大きく包み込みすぎない。
・和装らしい襟の折り返し、ゆったりした袖と袖口を付ける。袖は武器を持つ手や籠手が見える程度に整理する。
・袖の外側に少しゆとりを出すが、両腕が埋まる巨大な袖、足元まで垂れる振袖にはしない。
・肩・襟・袖には布の厚みを付け、紙の板や金属装甲に見せない。
・短い裾は動作時に軽く揺れる程度。長い尾やマント状の後ろ裾を追加しない。
・身頃は胴体、左右の袖は左右の腕に追従し、歩行・攻撃で袖だけが置き去りにならないようにする。
・鎧の肩装甲と羽織の肩・袖が食い込む場合は、肩装甲の大きさや羽織の余裕を調整して両立させる。

【鎧の形】
・兜、胸当て、脚甲、ブーツの4部位を別々に装備できる一式にする。
・兜は面頬や小さな冠状の飾りで魔法騎士らしさを出す。参考写真の顔や曲がった角をトレースしない。
・胸当ては、厚みのある上胸部・くびれた胴・横に張り出す肩装甲で輪郭を作る。
・肩は通常の鉄防具より存在感を出すが、頭の可動や腕振りを邪魔する巨大な板にはしない。
・前腕に籠手、膝とすねに独立した装甲、足にブーツの段差を付ける。
・ショート羽織と鎧を同時に装備して、肩・襟・背中で大きく食い込まないようにする。
・参考衣装の変身ベルトは作らず、必要なら普通の革帯や小さな留め具に置き換える。
・平面テクスチャだけで鎧を表現せず、肩・胸・籠手・膝の厚みは3D形状で作る。ただし細かすぎるメッシュにはしない。
・「タドルファンタジーのような魔法騎士」という第一印象と、Minecraftらしい簡潔さを両立する。

【現状のファイルについて】
同じフォルダの current-front.png / current-back.png は、以前のロングマントの仮モデルを灰色のマネキンに着せたソフトウェア描画です。新しいショート羽織の丈や形を表す資料ではありません。Minecraftのゲーム画面ではありません。完成見本・目標品質ではなく、サイズ感と現状の問題を把握するための資料です。
current-texture.png は現状の64×64 PNGです。
FantasyMantleRenderer.java と FantasyPatternQuad.java は旧ロングマントの描画コードです。装備への追従方式の参考にし、新しい羽織の丈・袖・前身頃・UVは作り直してください。FantasyKnightArmorModel.java と FantasyKnightArmorItem.java は鎧の仮実装です。既存の鎧の外見も完成見本ではなく、装備スロットや描画方式を確認するための資料です。
preview-generator.cjs は現状のテクスチャと確認画像を作る補助コードです。参考用コピーなので、内容を読まずに実行しないでください。リポジトリ直下から実行するとMOD側のアセットを書き換える設計です。
現状の細かい縦縞、硬い板に見える部分、肩周りの不自然さは改善して構いません。モデルの枚数や構造も、理由を説明したうえで改善できます。
この共有フォルダは参照資料です。リポジトリ全体のマント実装が、この共有コミットに統合済みという意味ではありません。

【技術条件】
Minecraft Java 1.20.1 / Forge向けです。ショート羽織は既存のCuriosマントスロットを流用し、鎧は通常のHEAD/CHEST/LEGS/FEETスロットを使います。
プレイヤーモデルの単位は16で1ブロック。胴体は幅8・高さ12・奥行4、脚は高さ12です。
旧ロングマントはHumanoidModelのbodyに追従し、背面のモデル座標 z=+3.2 付近に布を配置しています。新しい羽織はこれに前身頃・襟・左右の腕に追従する袖を加え、鎧の厚みに応じて配置を見直してください。モデルのy軸は下向きです。
旧モデルは全長約23モデル単位の7枚の布ですが、この丈や分割構造を新しい羽織へそのまま流用しないでください。身頃の丈は約10〜12を目安に再設計してください。
ショート羽織のテクスチャは64×64 PNGを基本にし、鎧は別の64×64または128×128 PNGとしてください。画素をぼかさず最近傍で扱ってください。UVを変えるなら新しい配置と対応するモデル変更をセットで提示してください。
旧モデルの背面UVは新しい羽織の仕様ではありません。前身頃・後ろ身頃・左右袖・襟・裏地を区別した新しいUV配置を提示し、袖の左右や前後で模様・陰影が逆にならないように確認してください。
黒い色だけでは見えなくなるため、明るい背景と暗い背景で輪郭・ひだの見え方を確認してください。
装備効果、攻撃機能、レシピ、キー操作、防具性能は今回変更しません。

【欲しい成果物】
1. まず各参考衣装から取り入れる点と、オリジナルにする点を短く説明。
2. ショート羽織＋鎧一式を同時に装備した前・後ろ・斜めの確認画像、および羽織を外した鎧だけの確認画像。同じ完成モデルを使い、実際の成果物の形とUVが分かるもの。
3. 実際に使うショート羽織用・鎧用のPNGテクスチャと、最近傍で拡大した確認画像。
4. 編集できるモデルデータ（Blockbench .bbmodelなど）、またはJavaモデルへ反映できる形状・UV変更。兜・胸当て・脚甲・ブーツ・ショート羽織を区別し、描画する部位を切り替えられる構造にする。
5. テクスチャの上下左右の向きと、各面にどう貼られるかの説明。

画像生成・ファイル出力機能が利用できる場合は実ファイルを出してください。利用できない場合は、その制限を最初に明示し、生成済みの画像があるようには言わず、再現可能なピクセル描画コードやモデルデータを出してください。説明文だけで終わらず、こちらで確認・編集・実装できる成果物を優先してください。
