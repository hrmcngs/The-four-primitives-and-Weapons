Minecraft Java版MODの「装備できる黒いロングマント」をデザインし、ゲームに使えるテクスチャと3Dモデルを作ってください。今回はマントだけが対象です。

【参考写真の使い方】
別途添付する、仮面ライダーブレイブ ファンタジーゲーマー レベル50の写真を参考にしてください。ただし、その衣装をそのまま再現してほしいわけではありません。
参考にするのは、肩から落ちる重い布、足首近くまである黒いロングマント、背面の広い面積、立体的な折れやひだ、前面を塞がず背中と体側を包むシルエットです。
鎧、顔、角、赤青の配色、ベルト、固有の意匠はコピーしないでください。オリジナルのファンタジー装備としてまとめてください。

【画風】
最優先は「実際のMinecraftに装備して違和感がないこと」です。
・バニラのプレイヤー体型に合う、角ばった立体モデル。
・マイクラらしい低解像度のドット絵。四角い画素、階段状の輪郭、少ない色数、2〜3段階の明確な陰影。
・黒を主体に、チャコール〜暗い青灰色を補助に使う。真っ黒で形が潰れない程度の控えめな明暗。
・質感は、厚手の布。薄い紙や板、ビニールに見せない。
・ひだの表現はモデル形状とテクスチャを合わせる。平面に細かい縦縞を貼っただけにしない。
・写実的な繊維、光沢、なめらかなグラデーション、ぼかし、アンチエイリアス、ノイズを避ける。
・翼、剣、紋章、刺繍、銀の縁取り、文字、ロゴなどの装飾は付けない。
・解像度の高いイラストを単に縮小してドット絵にするだけではなく、低解像度で読める形を設計する。

【形】
・肩に自然に乗る折り返しと、首の後ろの布の厚みを作る。
・前は開け、胸・腕・武器の操作を邪魔しない。
・背面は腰だけで終わらず、足首近くまで垂れる。
・下へ向けて少し広がり、裾には控えめな段差と布の落ち方を付ける。
・大きな肩鎧、鋭い金属の爪、巨大な立ち襟は今回追加しない。
・紙の短冊を並べた見え方、パーツ間の隙間、極端なギザギザの裾、過剰な横幅を避ける。
・歩行時に自然に揺らせるよう、上部と裾を分ける。静止時はまとまった一枚の布に見せる。

【現状のファイルについて】
同じフォルダの current-front.png / current-back.png は、現状の仮モデルを灰色のマネキンに着せたソフトウェア描画です。Minecraftのゲーム画面ではありません。完成見本・目標品質ではなく、サイズ感と現状の問題を把握するための資料です。
current-texture.png は現状の64×64 PNGです。
FantasyMantleRenderer.java と FantasyPatternQuad.java は現状の描画コードです。
preview-generator.cjs は現状のテクスチャと確認画像を作る補助コードです。参考用コピーなので、内容を読まずに実行しないでください。リポジトリ直下から実行するとMOD側のアセットを書き換える設計です。
現状の細かい縦縞、硬い板に見える部分、肩周りの不自然さは改善して構いません。モデルの枚数や構造も、理由を説明したうえで改善できます。
この共有フォルダは参照資料です。リポジトリ全体のマント実装が、この共有コミットに統合済みという意味ではありません。

【技術条件】
Minecraft Java 1.20.1 / Forge / Curiosの専用マントスロット向けです。
プレイヤーモデルの単位は16で1ブロック。胴体は幅8・高さ12・奥行4、脚は高さ12です。
現在はHumanoidModelのbodyに追従させ、背面のモデル座標 z=+3.2 付近に布を配置しています。モデルのy軸は下向きです。
現在は7枚の重なるパーツを使用し、各上部の高さ9、下部の高さ14から外側へ少し短くしています。全長は約23モデル単位です。
テクスチャは64×64 PNGを基本に、画素をぼかさず最近傍で扱ってください。UVを変えるなら新しい配置と対応するモデル変更をセットで提示してください。
現状の背面UVは、7枚を横にu=0〜1へ分割し、上下の分割位置はv=9/23です。サイドのUV、布の裏、肩の布も含めて確認してください。
黒い色だけでは見えなくなるため、明るい背景と暗い背景で輪郭・ひだの見え方を確認してください。
装備効果、攻撃機能、レシピ、キー操作、防具性能は今回変更しません。

【欲しい成果物】
1. まず写真から取り入れる点と、オリジナルにする点を短く説明。
2. 同一の完成モデルを使った前・後ろ・斜めの確認画像。見栄え用の別モデルではなく、実際の成果物の形とUVが分かるもの。
3. 実際に使う64×64のPNGテクスチャと、最近傍で拡大した確認画像。
4. 編集できるモデルデータ（Blockbench .bbmodelなど）、またはこのJavaモデルへ反映できる形状・UV変更。
5. テクスチャの上下左右の向きと、各面にどう貼られるかの説明。

画像生成・ファイル出力機能が利用できる場合は実ファイルを出してください。利用できない場合は、その制限を最初に明示し、生成済みの画像があるようには言わず、再現可能なピクセル描画コードやモデルデータを出してください。説明文だけで終わらず、こちらで確認・編集・実装できる成果物を優先してください。
