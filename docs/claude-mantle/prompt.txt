Minecraft Java版MODの「和風ファンタジーのショート羽織」単体をデザインし、ゲームに使えるテクスチャと3Dモデルを作ってください。羽織自体の形と着姿を優先します。

【参考衣装の使い分け・今回の変更点】
羽織の参考は「壱ノ桜・桜花」（初音ミク／Project DIVAの千本桜衣装）です。和装ジャケットの雰囲気を取り入れ、ファンタジー世界の服として自然に着られる短い羽織にしてください。足首まであるロングマントという以前の方向は取り消します。
参考衣装の確認先：
https://info.miku.sega.jp/3245
https://w.atwiki.jp/projectdiva_ac/pages/1865.html
可能ならユーザーが添付する壱ノ桜・桜花の画像を優先し、参照画像を確認できない場合は確認できたふりをしないでください。
羽織で参考にするのは、短い身頃、和装らしい襟と前合わせ、ゆったりした袖、和風とファンタジーが混ざる雰囲気です。帽子・スカート・髪型など衣装全体を再現する依頼ではありません。
衣装の形や模様をそのままトレースせず、オリジナルの和風ファンタジーの羽織としてまとめてください。参考は壱ノ桜・桜花の和装ジャケットの雰囲気に絞ります。

【画風】
最優先は「実際のMinecraftに装備して違和感がないこと」です。
・バニラのプレイヤー体型に合う、角ばった立体モデル。
・マイクラらしい低解像度のドット絵。四角い画素、階段状の輪郭、少ない色数、2〜3段階の明確な陰影。
・羽織は黒〜濃い紫を主体に、襟や袖口に落ち着いた差し色を少量使う。暗色でも形が読める控えめな明暗にする。
・羽織の質感は少し厚みのある布。布を薄い紙や板、ビニールに見せない。
・ひだの表現はモデル形状とテクスチャを合わせる。平面に細かい縦縞を貼っただけにしない。
・写実的な繊維、光沢、なめらかなグラデーション、ぼかし、アンチエイリアス、ノイズを避ける。
・羽織を大きな翼・剣の紋章や豪華な刺繍で埋めない。和風らしさは襟・袖・短い身頃を中心に表現し、柄を入れるなら低解像度でも読める控えめなものにする。文字・ロゴは付けない。
・解像度の高いイラストを単に縮小してドット絵にするだけではなく、低解像度で読める形を設計する。

【ショート羽織の形】
・腰あたりで終わる短い身頃。体格に合わせ、丈は肩から約10〜12モデル単位を目安にする。膝や足首まで伸ばさない。
・背中だけに短い布を付ける形ではなく、襟・前身頃・後ろ身頃・袖を備えた羽織ものとして設計する。
・前は開けるか軽く合わせ、下に着た普段着や帯が見えるようにする。着物のように胴を大きく包み込みすぎない。
・和装らしい襟の折り返し、ゆったりした袖と袖口を付ける。手元は見えるように整理する。
・袖の外側に少しゆとりを出すが、両腕が埋まる巨大な袖、足元まで垂れる振袖にはしない。
・肩・襟・袖には布の厚みを付け、紙の板や金属装甲に見せない。
・短い裾は動作時に軽く揺れる程度。長い尾やマント状の後ろ裾を追加しない。
・身頃は胴体、左右の袖は左右の腕に追従し、歩行・攻撃で袖だけが置き去りにならないようにする。
・普通のプレイヤー体型に着せ、肩から袖へのつながりと身頃のゆとりを自然に整える。

【現状のファイルについて】
同じフォルダの current-front.png / current-back.png は、以前のロングマントの仮モデルを灰色のマネキンに着せたソフトウェア描画です。新しいショート羽織の丈や形を表す資料ではありません。Minecraftのゲーム画面ではありません。完成見本・目標品質ではなく、サイズ感と現状の問題を把握するための資料です。
current-texture.png は現状の64×64 PNGです。
FantasyMantleRenderer.java と FantasyPatternQuad.java は旧ロングマントの描画コードです。装備への追従方式の参考にし、新しい羽織の丈・袖・前身頃・UVは作り直してください。
preview-generator.cjs は現状のテクスチャと確認画像を作る補助コードです。参考用コピーなので、内容を読まずに実行しないでください。リポジトリ直下から実行するとMOD側のアセットを書き換える設計です。
現状の細かい縦縞、硬い板に見える部分、肩周りの不自然さは改善して構いません。モデルの枚数や構造も、理由を説明したうえで改善できます。
この共有フォルダは参照資料です。リポジトリ全体のマント実装が、この共有コミットに統合済みという意味ではありません。

【技術条件】
Minecraft Java 1.20.1 / Forge向けです。ショート羽織は既存のCuriosマントスロットを流用します。
プレイヤーモデルの単位は16で1ブロック。胴体は幅8・高さ12・奥行4、脚は高さ12です。
旧ロングマントはHumanoidModelのbodyに追従し、背面のモデル座標 z=+3.2 付近に布を配置しています。新しい羽織はこれに前身頃・襟・左右の腕に追従する袖を加え、プレイヤーの体型に合わせて配置を見直してください。モデルのy軸は下向きです。
旧モデルは全長約23モデル単位の7枚の布ですが、この丈や分割構造を新しい羽織へそのまま流用しないでください。身頃の丈は約10〜12を目安に再設計してください。
ショート羽織のテクスチャは64×64 PNGを基本にしてください。画素をぼかさず最近傍で扱ってください。UVを変えるなら新しい配置と対応するモデル変更をセットで提示してください。
旧モデルの背面UVは新しい羽織の仕様ではありません。前身頃・後ろ身頃・左右袖・襟・裏地を区別した新しいUV配置を提示し、袖の左右や前後で模様・陰影が逆にならないように確認してください。
黒い色だけでは見えなくなるため、明るい背景と暗い背景で輪郭・ひだの見え方を確認してください。
装備効果、攻撃機能、レシピ、キー操作、防具性能は今回変更しません。

【欲しい成果物】
1. まず参考衣装から取り入れる点と、オリジナルにする点を短く説明。
2. 普通のプレイヤー体型にショート羽織を着せた前・後ろ・斜めの確認画像。同じ完成モデルを使い、実際の成果物の形とUVが分かるもの。
3. 実際に使うショート羽織用のPNGテクスチャと、最近傍で拡大した確認画像。
4. 編集できるモデルデータ（Blockbench .bbmodelなど）、またはJavaモデルへ反映できる形状・UV変更。羽織の身頃・襟・左右の袖を分け、胴体と左右の腕に追従できる構造にする。
5. テクスチャの上下左右の向きと、各面にどう貼られるかの説明。

画像生成・ファイル出力機能が利用できる場合は実ファイルを出してください。利用できない場合は、その制限を最初に明示し、生成済みの画像があるようには言わず、再現可能なピクセル描画コードやモデルデータを出してください。説明文だけで終わらず、こちらで確認・編集・実装できる成果物を優先してください。
